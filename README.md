# Music Playlist Management  A **Data Structures mini project** developed in **C++** to manage and organize a music playlist using **linked lists**. The project demonstrates practical implementation of core data structure concepts along with **Object-Oriented Programming (OOP)**.  ### Features - Add songs to the playlist - Delete songs using their Song ID - Display the complete playlist - Play the current song - Navigate to the **next** and **previous** songs - Manage songs dynamically using linked-list structures  ### Technologies Used - **C++** - **Object-Oriented Programming (OOP)** - **Singly Linked List** - **Doubly Linked List**  This project was created as part of a **Data Structures** mini project to understand how linked lists can be applied to a real-world problem such as music playlist management.
